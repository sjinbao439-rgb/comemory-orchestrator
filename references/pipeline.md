# 九环节处理规范

处理主线：背景建档 → 流式转写 → 事件理解 → 语义分镜 → 节奏编排 → 提示词与首帧 → 视频生成 → 补充修订 → 收束归档。补充信息可从任一阶段回到对应事件，形成持续更新的闭环。

## 1. 背景建档

**输入**：讲述主题、人物背景、参考资料、服务配置。

**处理**：建立会话编号；分别记录当前身份与回忆身份；整理年代、地点、人物关系及照片对应对象。读取输入格式、支持时长、查询方式与任务控制参数。已有文字和首帧可直接进入对应阶段。

**输出**：人物背景、资料索引、能力配置及会话状态。背景信息随讲述逐步充实，保持一次设置、持续复用。

## 2. 语音转写

**输入**：音频流、录音文件或文字。

**处理**：接收临时稿与确认稿，为原话分配稳定编号。相同编号原位更新，重连按编号和确认范围恢复。保留原文、角色、起止时间及识别置信信息；在人名、地名和年代上结合背景热词复核。

**输出**：确认原话序列、临时稿、音频时间轴和补充记录。低置信词保留原识别结果及复核标记，后文出现完整称谓时再对齐。

**转入条件**：确认稿进入语义分析。语音活动检测提供停顿位置，事件完整性由下一环节判断。

## 3. 事件理解与事实溯源

**输入**：确认原话、背景及上一版事件状态。

**处理**：区分叙述、疑问、假设、否定和自我纠正，提取人物、时空、行动、物件、显式情绪和先后关系。指代按同一事件与最近明确对象解析；多个对象均符合时保留原称谓，等待后文定位。

**输出**：事件状态及事实表。每条事实包含内容、来源和表达类型：直接陈述、前文继承、保留语气。例如“好像1982年”保留“大约”的表达，当前年龄单独存放。

**处理规则**：提问提供对话线索，回答提供事件依据；否定进入画面排除项；时代背景约束视觉环境，具体事件以口述来源为依据。

## 4. 语义分镜

**输入**：事件状态、缓冲语句及已有场景。

| 判断条件 | 处理动作 | 记录依据 |
|---|---|---|
| 主体、行动及必要对象形成独立画面 | 提交场景 | 事件摘要、原话及切分理由 |
| 同一时空、同一行动增加细节 | 扩充原场景 | 新增事实及来源 |
| 转向新时空或主要行动 | 收束前一完整事件，建立后续场景 | 转折原话及事件顺序 |
| 动作句仍在展开 | 继续缓冲 | 缓冲原话与等待的语义成分 |
| 同一事件中出现停顿 | 保持场景，记录停顿 | 事件的连续关系 |
| 长叙述包含多个完整子行动 | 按子行动拆分 | 每个子行动的起止来源 |
| 追问后补充答案 | 合并到对应事件 | 问答关系及回答来源 |
| 输入内容与已有版本相同 | 复用当前计划 | 输入编号及内容比对结果 |

**输出**：场景编号、事实来源、计时来源、事件摘要、切分理由、连续性编号和缓冲记录。提交前复核主体指代、否定和行动对象。

## 5. 节奏与时长编排

**输入**：计时来源、音频区间、文字长度、服务支持时长及时间配置。

**处理**：

1. 选择计时范围。同一完整事件使用起止跨度，保留内部停顿；跨越无关问答的来源使用有效区间并集。继承背景只进入事实来源。
2. 计算目标展示时长。音频使用时间戳；纯文字按配置语速估算，并记录计时类型。
3. 匹配生成长度。将目标分配到服务支持的片段时长，生成后裁剪多余部分；每片展示时长之和等于事件目标。
4. 复查长事件。超过配置阈值时检查完整子行动，决定独立成镜或连续分片。

**输出**：计时类型、计时范围、原话时长、展示目标、生成秒数、裁剪秒数与片段顺序。使用 `timing.cjs` 计算并校验数值。

**示例**：一句原话跨度1.1秒，服务支持5秒，则生成5秒、展示1.1秒、裁剪3.9秒。长事件采用连续动作分片，避免同一动作重复起播。

## 6. 提示词与首帧

**输入**：场景事实、参考资料、连续性编号与时长计划。

**首帧组织**：年代与地区 → 主体及相对位置 → 环境与关键物件 → 视角与构图 → 色彩与光线。

**动态组织**：主要行动 → 行动进展 → 环境自然运动 → 镜头运动 → 与前片的承接要求。

**排除项**：口述否定、时代错置、人物或物件畸变、闪烁、水印及画面文字。

**处理**：先生成或选定首帧，核对事实和空间关系后提交视频。照片与口述冲突时，保持口述事件，分开记录照片的适用对象和冲突细节。缺少外观参考的主体采用第一人称、背影或局部构图。

**连续片段**：第一个片段使用场景首帧；后片依赖前片解码提取并校验的末帧。每片提示词描述原行动的连续进展。采用独立片段的服务路线时，各片使用明确的动作起止和稳定参考组织承接。

**输出**：首帧提示词、动态提示词、排除提示词、参考素材及片段依赖。任务键、版本、秒数和裁剪值放入结构化参数。

## 7. 异步生成与增量发布

**输入**：校验后的计划、当前版本、参考帧和执行预算。

**处理**：

1. 以会话、场景、版本、片段编号组成幂等任务键，持久化后提交。
2. 依赖链内按顺序生成；互不依赖的场景在并发预算内执行。
3. 查询任务并取得媒体，检查任务键、当前版本、文件解码、时长、编码及关键画面内容。
4. 校验成功后进入就绪队列，依叙事顺序发布。多片场景完成片段集合和拼接校验后更新整场景状态。
5. 对失败任务按重试次数和截止时间处理，保留原话、成功素材及错误记录。过时结果退出发布流程。

**状态链**：计划 → 排队 → 生成 → 就绪／失败；版本被替换时转为过时。

**呈现节奏**：讲述持续进行，生成在后台推进；首帧可先行预览，动态素材就绪后接入播放。记录“原话确认至首帧”“原话确认至视频就绪”两项延迟，以队列积压调整并发和分镜提交频率。

## 8. 补充纠正与版本更新

**输入**：新原话、目标事件线索、已有事实及任务状态。

**处理**：先定位目标场景，再区分细节补充和事实纠正。纠正保留替换前后内容、来源和版本，场景编号稳定。沿人物、物件、时空依赖查找受影响的后续场景，按影响范围更新。

| 当前阶段 | 更新动作 |
|---|---|
| 计划阶段 | 修改事实、提示词和时长计划 |
| 排队或生成阶段 | 递增版本，取消旧任务或标记过时，提交新版 |
| 已播放阶段 | 保留当前对话节奏，加入后续修订队列 |
| 重传相同更新 | 复用已有版本和任务键 |

**输出**：新场景版本、修订记录、受影响场景清单及队列动作。尚待定位的补充内容存入会话记录，继续结合后文匹配。

## 9. 收束与归档

**输入**：结束指令、缓冲原话、任务状态、播放反馈与保存反馈。

**处理**：整理缓冲区，保留完整子事件和其余原话记录；等待当前任务至截止时间，将超时任务置为失败并停止接收其播放结果。播放序列结束后生成归档清单，按成功素材形成完整视频、部分视频或文字记录归档。

**输出**：标题、摘要、记录时间、原话、场景顺序、提示词、媒体、时长依据及修订记录。保存完成后记录地址与保存时间。

## 执行校验

- 每条画面事实能定位到讲述者的确认原话，语气与否定完整保留。
- 每个场景写明成镜理由，计时来源与事实来源分别记录。
- 展示时长总和等于事件目标，生成长度符合服务配置。
- 人物和物件引用稳定，后续片段使用对应参考帧与动作进展。
- 同一任务保持幂等，旧版本回调退出发布队列。
- 失败和超时有终态，原话与成功素材持续保留。
- 后台编排随对话推进，集中复核放在自然停顿或结束阶段。
